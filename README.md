🛠 Tasks & Methodology1. Handling Missing ValuesPrice Imputation (Price ($)):Issue: Blank price entries skew total valuation and basic summaries.Solution: Imputed blanks using the mean average of valid price entries with an absolute reference range.Formula:=IF(ISBLANK(H2), AVERAGE($H$2:$H$32), H2)
Category Backfilling (Category):Issue: Unassigned product classifications.Solution: Identified null cells and populated them with "Unknown" (or inferred from context).Formula:=IF(ISBLANK(K2), "Unknown", K2)
2. Correcting Inconsistent DataStandardizing Text & Whitespace:Issue: Inconsistent casing and trailing/leading accidental spaces in Product Name.Solution: Applied TRIM to strip unwanted whitespace and PROPER for uniform title casing.Formula:=PROPER(TRIM(D2))
Correcting Category Typos:Issue: Misspelled category names (e.g., "Electrnics" instead of "Electronics").Solution: Utilized Excel's global Find & Replace dialog (Ctrl + H) to ensure clean categorical groupings.3. DeduplicationEliminating Duplicate Records:Issue: Identical repeated rows inflating inventory and product counts.Solution: Ran the native Remove Duplicates utility (Data > Data Tools > Remove Duplicates) across all columns (A:K) to retain only unique product transactions.4. Feature Extraction & EngineeringSplitting Composite Product ID (e.g., 28-JAN-US):Manufacturing Date: Parsed the date string component (day and month) and converted it into a serial date value.=DATEVALUE(LEFT(A2, 6) & "-2026")
Country Code: Extracted the terminal 2-character country identifier.=RIGHT(A2, 2)
Merging Brand and Product:Combined separate Brand and Product Name fields into a unified Product Brand column for clearer labeling.Formula using TEXTJOIN:=TEXTJOIN(" ", TRUE, E2, D2)
Formula using concatenation:=E2 & " " & D2
